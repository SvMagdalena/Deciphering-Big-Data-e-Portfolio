Unit 4 — Data Cleaning

UNICEF Survey: mn.csv and mn_headers.csv

This exercise introduced a survey dataset and a separate lookup file describing its abbreviated headings. Checking the files identified 9,008 survey records and 159 columns with 150 headings, out of these, matching the lookup directly and nine not. A further check found 606,612 NA values but no empty string cells. I learned why an unavailable response cannot be automatically treated as a mistake, because in survey data, a question sometimes does not apply to every person filling out the survey. The approach preserved unmatched column codes rather than discarding information.

Scripting the Cleaning Process — Chapter 8

I also studied the complete Python cleaning script from Chapter 8 of Data Wrangling with Python. This introduced the importance of writing reusable functions, documenting code and using validation checks throughout the cleaning process. According to the reading, organising code properly makes it easier to understand, repeat and troubleshoot, in particular when working with large datasets.
