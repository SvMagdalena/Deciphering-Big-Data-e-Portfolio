E-Portfolio — Deciphering Big Data

Welcome to my e-portfolio for the Deciphering Big Data module at UoEO. This portfolio includes my assignments, formative activities and reflections on what I have learned throughout this module.

During this module, I explored how raw data can be transformed into meaningful information with data cleaning, database design, programming and visualisation. I also developed a better understanding of the challenges involved in handling data, particularly when accuracy, security and business context and logic are important.

The main project of this module focused on developing an AI-assisted database and analytics for Collateralised Loan Obligations (CLOs) within a custodian bank’s Corporate Trust team. During this project, I was able to combine what I learned in this module with my financial services background to deliver a proposal and test how AI can help extract and explain CLO data. Alongside this, I completed practical learning activities involving Python, data cleaning, database normalisation, SQL and API security.

This ePortfolio documents both the technical work I did and my personal development, including the challenges I encountered, decisions I made and the areas where I would like to improve going forward.
