Reflection and Development

Technical Skills Learned

This module strengthened my knowledge of Python, Pandas, SQL, SQLite, Power BI and AI-assisted analysis. More importantly, it also developed my ability to ask whether results make sense rather than accepting an output simply because a tool produced it and prompted me to verify the results.

Professional Skills Matrix

Critical Reflection

My full reflection on the module is submitted separately in the assignment submission window. The most valuable part of this module was applying the technical concepts to similar to a real life financial dataset I could relate to. Although AI helped me with Python code and interpreting the final dashboard, I learned that AI's outputs need to be checked carefully, particularly when financial data and business logic need to be involved. I also found that data cleaning requires more judgement than I expected. Missing or inconsistent values cannot always be corrected automatically with estimates or averages. Completing the coursework independently helped me develop my problem solving and time management skills, although I missed the opportunity to learn through group work and collaboration. Going forward, I want to become more confident working with Python and SQL, improve my ability to validate analytical results and gain more experience working with others on technical projects.

Professional Development

Going forward, I want to write more Python, become more confident with complex SQL queries and improve my Power BI reporting. I also want to continue learning more about data governance and validation and how these concepts get applied in financial services. Lastly, I would also like to be able to contribute more to discussions and collaborate on future team projects with my peers.
