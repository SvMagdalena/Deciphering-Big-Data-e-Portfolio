Formative Activities

Throughout the module, I have engaged in a number of formative activities:

Unit 3 - Web Scraping

The Unit 3 topic introduced extracting structured information from HTML and checking the suitability of the source. As a small supporting demonstration, Python parsed a saved copy of the Forty template homepage and extracted its page title, headings and internal page links.

Unit 4 - Data Cleaning & Test

The UNICEF survey exercise, lecturecast materials and Data Management Pipeline Test from Unit 4 are covered on a separate page of this e-portfolio.

Unit 7 - Normalisation and Database Build

Using a fictional student dataset provided by the lecturer, the exercise followed 1NF, 2NF and 3NF and tested a five table relational database (please see "UNIT 7 NORMALISATION").

Unit 8 - GDPR Discussion

The discussion topic for this unit compared GDPR security principles with UK's ICO guidance. I did not participate in the discussion due to personal circumstances I was experiencing at the time, so no forum post or peer feedback is provided. GDPR and ICO reinforced need for appropriate technical and organisational security measures when handling personal data.

Unit 10 - API Security and QRadar Integration

See "UNIT 10 SECURITY" for the API risk assessment and reading on IBM QRadar, INTELLAS and KAIF. They explore secure data exchange, validation and event parsing.

Unit 11 - Backup Procedure

The main finding from the article is that a backup should be useful only if it can be restored successfully. The restored database retained five students and 15 enrolments, passed PRAGMA integrity_check and returned zero foreign key violations.
